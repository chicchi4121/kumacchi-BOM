# くまっちボム！ (Phase1: ゲーム基盤)

ボンバーマン系対戦アクションゲーム。本リポジトリは開発仕様書のPhase1
（Phaser環境構築・プレイヤー移動・マップ生成・爆弾・爆発・当たり判定）
までを実装したものです。

## 動かし方

ES Modulesを使用しているため、`file://`で直接開くとCORSエラーになります。
簡易サーバーを立ち上げてアクセスしてください。

```bash
npm run dev
# もしくは
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

## テスト

Phaser非依存のコアロジック（マップ生成・爆風伝播・乱数）に対する
簡易ユニットテストを同梱しています。

```bash
node test_phase1.mjs
```

## 操作方法

- 矢印キー（↑↓←→）: 移動
- Space: 爆弾設置
- Esc: ポーズ
